# BLACK — сайт + мессенджер (демо)

Учебный прототип по сценарию:

1. На **сайте** регистрация / вход по почте.
2. Генерация **виртуального** номера любой страны, включая демо-номер +888 (за кредиты).
3. На сайте крутится **код каждые 20 секунд**.
4. В **приложении** вводишь этот номер и код — вход.
5. Дальше чаты, медиа, голосовые, интерфейс звонков, профиль и настройки.

Это **не оператор связи**. Номера не принимают настоящие SMS. Не используй проект, чтобы обходить чужие проверки, спамить или обманывать людей.

## Как запустить

Нужен локальный http-сервер (модули ES не работают с `file://`).

```bash
cd black-social
python3 -m http.server 8080
```

Открой:

- сайт: http://localhost:8080/
- вход: http://localhost:8080/login.html
- номера: http://localhost:8080/dashboard.html
- мессенджер: http://localhost:8080/app.html

На телефоне открой тот же адрес в Wi‑Fi (IP компьютера) и «Добавить на экран Домой».

## Что включить в Firebase Console

Проект: `black-social-af844`

1. Authentication → Sign-in method:
   - Email/Password
   - Anonymous (для входа из приложения после проверки кода)
2. Realtime Database → Rules — вставь содержимое `database.rules.json` и опубликуй.
3. Storage → Rules (если хочешь загрузку фото/видео в облако):

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /media/{userId}/{allPaths=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

Если правила закрыты и методы Auth не включены, сайт покажет ошибку при регистрации / записи номера.

## Что реально работает

- Регистрация и вход по почте (Firebase Auth).
- Генерация номера, баланс кредитов, ротация кода 20 сек, запись в RTDB.
- Проверка кода приложением по той же базе.
- Локальные чаты + живые чаты `live_*` через RTDB, если открыть чат по номеру.
- Запись голосовых через микрофон браузера.
- Выбор фото/видео; загрузка в Storage, если правила позволяют, иначе превью локально.
- Интерфейс аудио/видеозвонка (визуальный прототип, не телефонная сеть).

## Чего здесь нет

- Настоящих SIM / SMS / номеров ITU +888.
- Публикации в App Store / Google Play.
- Платежного шлюза. Кнопка «+10 демо» только начисляет учебные кредиты.
